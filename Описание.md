## 1. Общая структура проектов

Лабораторные работы оформлены как общий CMake-проект с тремя самостоятельными подпроектами:

```text
.
├── CMakeLists.txt              # общий CMake-файл, подключает подпроекты
├── sets/                       # темы "1 - Множества" и "2 - Множество как объект"
│   ├── CMakeLists.txt
│   ├── src/
│   │   ├── common.hpp          # универсум, проверка символов, общая формула варианта
│   │   ├── main.cpp            # CLI: ручной ввод, тесты, бенчмарк
│   │   ├── structures/         # реализация множеств через структуры
│   │   └── classes/            # реализация множеств через классы
│   └── tests/
│       ├── generator.cpp
│       └── generator.hpp       # генерация тестовых наборов
├── tree/                       # тема "3 - Деревья"
│   ├── CMakeLists.txt
│   └── src/
│       ├── binary_tree.hpp     # интерфейс класса дерева
│       ├── binary_tree.cpp     # построение, разметка, обход, подсчет потомков
│       └── main.cpp            # CLI: тестовое или ручное дерево
└── graph/                      # тема "4 - Графы"
    ├── CMakeLists.txt
    ├── src/
    │   ├── graph.hpp           # интерфейс графа и глубинного стягивающего леса
    │   ├── graph.cpp           # Реализация графа, алгоритма DFS
    │   └── main.cpp            # CLI: связный/несвязный граф, запуск с фиксированным или генерированным графом
    └── tests/
        ├── graph_generator.cpp
        └── graph_generator.hpp # генерация случайных графов
```

## 2. Подробное описание (инструкции по сборке см. ниже)

### `sets` - темы 1 и 2: "Множества" и "Множество как объект"

Вариант 31:

| Параметр           | Значение                                                                                                         |
| ------------------ | ---------------------------------------------------------------------------------------------------------------- |
| Универсум          | Знаки операций C++                                                                                               |
| Что надо вычислить | Множество, содержащего операции, имеющиеся в `A`, также одновременно в `B` и `C`, и все операции из `D`          |

В проекте есть два варианта сборки:

- `sets_structs` - реализация через структуры данных;
- `sets_classes` - реализация через классы.

Для каждой реализации используются четыре способа представления множества:

- массив;
- список;
- массив битов;
- машинное слово.

Приложение поддерживает ручной ввод, автоматические тесты и бенчмарк.
Флаги запуска одинаковы для двух исполняемых файлов: `sets_structs` и `sets_classes`.

- `--help`, `-h`      - вывод справки по доступным режимам запуска.
- `--manual`, `-m`    - ручной ввод четырех множеств `A`, `B`, `C`, `D`.
- `--test`, `-t`      - запуск автоматических тестов на сгенерированных наборах данных.
- `--benchmark`, `-b` - запуск измерения времени выполнения формулы для разных способов хранения множества.
- `--verbose`, `-v`   - подробный вывод результатов автоматических тестов.

Флаги `--manual`, `--test` и `--benchmark` могут использоваться совместно в одном запуске. Флаг `--verbose` влияет на подробность вывода автоматических тестов.

Команда запуска с тестами и подробным выводом после сборки из корня проекта:

```bash
./build/sets/sets_structs --test --verbose && ./build/sets/sets_classes --test --verbose
```

## 3. Требования к сборке

Для сборки нужны:

- CMake версии 3.16 или новее;
- компилятор C++ с поддержкой стандарта C++23;
- сборочная система, поддерживаемая CMake;
- стандартная библиотека C++ без дополнительных внешних зависимостей.

## 4. Инструкция по сборке

Рекомендуемый способ сборки:

```bash
cd Algorithms_Strutures
mkdir build
cmake -S . -B build
cmake --build build
```

После сборки исполняемые файлы находятся в подпапках каталога `build`:

```text
build/sets/sets_structs
build/sets/sets_classes
build/tree/tree
build/graph/graph
```
